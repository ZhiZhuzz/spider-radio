# 架构概览

Android `MainActivity` 承载 WebView 界面，处理文件选择、曲库和原生桥入口。`RadioService` 承担播放状态、音频焦点、来源切换、环境音混合、重试及定时等流程。

`SystemMediaOutput` 根据播放快照输出通知和系统媒体状态；`MediaArtwork` 处理媒体封面。曲库、队列、来源加载、探测和媒体展示的一部分逻辑已拆分为可单独验证的类。

前端按核心配置、场景、曲库、设置、路由、播放状态和事件绑定拆分。WebView 原生桥仍使用全局函数入口；没有迁移到新前端框架。播放服务仍管理较多状态，不能把 v0.8.3 的整理描述为已经解决所有维护问题。

更多变更见根目录 CHANGELOG-0.8.3.md。
