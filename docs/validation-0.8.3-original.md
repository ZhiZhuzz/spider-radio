# 蜘蛛电台 Android v0.8.3 验证报告

日期：2026-10-08。基线：安卓 v0.8.2。范围：前端局部重写、系统媒体发布职责拆分、测试及构建维护。

## 完成内容

- 前端 `show()`、`nativeState()`、关闭与返回入口各自收敛为一份定义；不再保存旧函数后逐层覆盖。
- 曲库、调音台、设置和其他页面直接生成最终结构，保留原有原生桥回调。
- 全部脚本定义完成后统一绑定事件，样式移入独立 CSS，保持原样式层叠顺序。
- 原生播放状态集中同步，有设置变化时每个快照写入一次，相同快照不重复写入。
- 通知、元数据、PlaybackState 与媒体诊断由 `SystemMediaOutput` 根据只读快照发布。
- 原有播放器、混音、网络重连、音频焦点、资源释放和定时流程保留；Java 源码统一排版。
- 统一测试入口包括原有测试及先前遗漏的定时、DOM 和淡化专项；新增交错交互与媒体发布器检查。
- 增加锁定的 Node 依赖和可移植浏览器加载路径；修正 CI 过期版本和交互式步骤，但未在 GitHub 执行工作流。

## 保留边界

前端仍使用全局函数作为 WebView 原生桥与 HTML 事件的入口，没有引入新的框架或打包器。播放服务仍管理较多状态；本轮只拆出职责明确的系统媒体发布，未宣称彻底解决所有维护风险。

覆盖安装使用同一证书的旧版通常不需要卸载。本次没有存储格式迁移。不要先卸载，以免丢失应用内副本。真机验收清单见 DEVICE-TEST-0.8.3.md。

源码包不包含签名私钥、密码、node_modules 和构建缓存；旧版本记录明确放在 history/。源码恢复构建检查另见 verification-083/restore-check.json。
